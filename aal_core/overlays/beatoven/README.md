# BeatOven Overlay (v0.1)

BeatOven is an AAL overlay module that renders Abraxas Oracle signals into deterministic music-control artifacts.
No forecasts. No network. Local-only logging. ABX-Runes-only coupling.

Inputs:
- OracleSignalLayer.v2 envelope
- Optional overlays: AAlmanac, SemioticWeather, MemeticWeather, ABX-GT

Outputs (artifacts):
- beatoven_midi_pack.v0.json
- beatoven_cv_pack.v0.json (optional)
- beatoven_session_recipe.v0.md
- provenance_manifest.v0.json
- determinism_report.v0.json

Governance:
- Shadow metrics are sonified/visualized only; they never affect predictions or promotion.
