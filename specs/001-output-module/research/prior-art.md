# Prior art: Output Module (PROPOSED)

Survey date: 2026-11-11. All "seen" prices are as read on that date. Labels used on every claim: OBSERVED (read at the cited URL in this session), INFERRED (reasoning, basis stated), SPECULATIVE. "not published" means the page or repo I read does not state it. Where a page was only read through a search-result excerpt or an extraction query (not the full page), the row says so and confidence is lowered.

BeatOven differentiators referenced in the table (from the brief, not from outside sources):
- D1: input is a symbolic Oracle signal, not notes a human sequenced.
- D2: SEED determinism (identical inputs give identical jack outputs, hash-chained provenance).
- D3: timestamped look-ahead scheduling on the device, not play-on-arrival.
- D4: fail-closed on timing loss (gates low, CV to a safe value).
